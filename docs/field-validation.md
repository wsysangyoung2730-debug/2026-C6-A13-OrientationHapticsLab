# 착용 검증 절차

이 문서는 실제 시험 결과가 아니라 수행할 검증 절차입니다. 앱의 계산 테스트와 시뮬레이터 빌드는 실제 착용 정확도나 진동 인지를 보장하지 않습니다.

## 시험 조건 기록

아이폰 모델 / iOS 버전 / 케이스 / 밴드 재질·조임 / 옷 두께 / 시험자 / 날짜를 기록합니다. 앱을 전면에 열어 화면을 켜고 배 앞쪽 허리에 세로 고정합니다. 화면은 바깥쪽입니다.

## 1. 패턴 구분

설정에서 좌우 30°·45°·90°를 각각 미리 재생합니다. 화면을 보지 않고 어떤 신호인지 응답하도록 한 뒤 순서를 바꿔 반복합니다. 식별 성공 횟수, 혼동한 조합, 너무 약하거나 불편한 패턴을 기록합니다. 세기뿐 아니라 패턴을 바꿔 비교합니다.

## 2. 각도 검증

바닥에 기준선과 좌우 30°·45°·90° 선을 표시합니다. 기준선에서 리셋하고 각 선으로 10회씩 회전해 화면 각도, 신호 발생, 누락·중복을 기록합니다. 초기 오차 목표는 ±5°이며 실측 결과로 판단합니다. 몸을 약간 숙이거나 좌우로 기울여 방향값이 달라지는 정도도 기록합니다.

경계에서 작게 흔들기, 천천히 통과하기, 30°와 45°를 빠르게 연속 통과하기, ±180°를 넘기기, 한 바퀴 돌기, 다시 되돌아가기 모두 확인합니다. 빠른 통과에서는 가장 최근 도달한 신호가 우선하므로 지난 신호가 길게 이어지면 실패입니다.

## 3. 공연 동작 한 사이클

1. 보조자가 몸의 정면을 정렬합니다.
2. 화면 버튼으로 0°를 설정합니다.
3. 앞으로 7걸음 이동합니다.
4. 왼쪽 30°(11시 방향)로 회전해 신호를 확인합니다.
5. 로그에 보관할 값들을 확인한 뒤 다시 리셋합니다.
6. 새 사이클이 0°·0걸음·(0,0)에서 시작하고 이전 값은 로그에 남는지 확인합니다.

걸음 수는 수동 계수와 비교합니다. 이동 거리는 줄자로 확인한 거리와 비교하되 추정 좌표 결과를 방향 검증과 분리해 기록합니다. 걷고 즉시 리셋하거나 리셋을 연속해서 눌러도 이전 사이클 걸음이 새 사이클에 들어오면 안 됩니다.

## 4. 화면·설정·중단

- 각도별 진동 사용 여부와 패턴·세기·선명도를 변경하고 앱 재실행 후 유지되는지 확인합니다.
- 해당 신호 재생 중 전체 화면이 단색이고 방향과 각도가 큰 글씨로 표시되는지 확인합니다.
- 신호 종료·취소·새 신호·리셋·앱 중단 시 오래된 화면이 남지 않는지 확인합니다.
- 동작 권한 거부, 화면 잠금, 앱 전환, 다시 실행을 확인합니다.
- 중단 이후 앱이 이전 기준을 유효한 것처럼 사용하지 않고 재리셋을 요구하는지 확인합니다.
- VoiceOver로 리셋·측정 중지·설정·로그를 사용할 수 있는지 확인합니다.
